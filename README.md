# ФЛЁР — демо-лендинг салона красоты

Одностраничный сайт для салона красоты: светлая тема, серифная типографика,
терракота. Волосы, ногти, брови и макияж, запись с выбором свободного времени.

Чистый HTML + CSS + JS, без сборки и зависимостей. Открывается двойным кликом
по `index.html`.

> **Это демо, а не сайт реального бизнеса.** Название, мастера, отзывы, адрес,
> телефон и цены вымышлены. Перед продажей владельцу нужно заменить данные
> на настоящие (список ниже).

## Что внутри

```
salon/
├── index.html          разметка всех секций + микроразметка HairSalon
├── css/style.css       тема, сетки, адаптив
├── js/main.js          меню, липкая шапка, анимации, маска, слоты, форма
├── assets/
│   ├── hero.jpg        интерьер салона
│   ├── makeup.jpg      кисти для макияжа
│   ├── nails.jpg       маникюр
│   └── hair.jpg        уход и укладка
└── README.md
```

## Секции

1. **Первый экран** — заголовок, две кнопки, часы / адрес / запись, рейтинг.
2. **Бегущая строка** — список услуг.
3. **Услуги** — три группы: волосы, ногти, брови и макияж. Цены без «от».
4. **Работы** — галерея из трёх фото + цитата мастера.
5. **Мастера** — три карточки со специализациями.
6. **Отзывы** — три отзыва.
7. **Сертификат** — тёмный блок с оффером.
8. **Запись** — форма: услуга, мастер, дата и **сетка свободных окон**.
9. **Контакты** — адрес, часы, телефон, мессенджеры, схема.

## Что умеет JavaScript

- Липкая шапка, мобильное меню, появление блоков при прокрутке.
- Маска телефона `+7 (999) 123-45-67`.
- Дата: только сегодня и 60 дней вперёд.
- Сетка времени: занятые окна отмечены и недоступны, прошедшие часы
  для сегодняшнего дня тоже. Набор занятых окон стабилен для каждой даты,
  поэтому расписание не «прыгает» при кликах.
- Заявка собирается в текст и открывает Telegram с готовым сообщением.
- Валидация имени, телефона, услуги, даты и времени.

## Как открыть локально

Двойной клик по `index.html`. Если браузер не открывает относительные пути
к CSS и JS с диска, запустите в папке:

```
python -m http.server 8000
```

и откройте `http://localhost:8000/`.

## Как опубликовать на GitHub Pages

1. Создать репозиторий `salon-demo` (public).
2. **Add file → Upload files**, перетащить **содержимое** папки `salon`
   (`index.html`, `css`, `js`, `assets`, `README.md`).
3. **Settings → Pages** → Source: **Deploy from a branch** →
   Branch `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу
   `https://<ник>.github.io/salon-demo/`.
